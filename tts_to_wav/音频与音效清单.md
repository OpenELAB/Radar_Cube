# Audio and Sound Asset List

All resources use `16 kHz / mono / 16-bit PCM WAV`, and the file names use lowercase ASCII, snake_case and `.wav` suffixes.

Test mode and configuration mode do not use independent audio resources.

| Category | Name | Filename | Type | Spoken text / sound description | Use cases |
| --- | --- | --- | --- | --- | --- |
| System | Startup | `boot.wav` | Short sound effect | Short startup tone | Power on |
| System | Shutdown | `sys_shutdown.wav` | Voice | System shutting down | Sleep or power off |
| Mode | Unpaired | `mode_unpaired.wav` | Voice | Device not paired | No sensor is paired |
| Mode | Pairing | `mode_pairing.wav` | Voice | Entering pairing mode | Pairing begins |
| Mode | Factory reset complete | `mode_factory_reset_done.wav` | Voice | Factory settings restored | Factory reset completes |
| Status | Success tone | `tone_success_up.wav` | Short sound effect | Short rising tone | Pairing, wake-up, or link restoration succeeds |
| Status | Warning tone | `tone_warning_down.wav` | Short sound effect | Short falling tone | Pairing or wake-up fails; one or both links are lost |
| Pairing | Both sensors paired | `pair_ok_both.wav` | Voice | Radar pairing complete | Both sensors are paired |
| Wake-up | Both sensors connected | `wake_ok.wav` | Voice | Radar connected | Both sensors wake up |
| Power | Controller battery low | `power_low.wav` | Voice | Controller battery low | Controller reaches low battery threshold |
| Power | Controller battery critical | `power_critical.wav` | Voice | Battery critically low. Shutting down soon | Controller reaches critical battery threshold |
| Power | Left sensor battery low | `power_sensor_low_left.wav` | Voice | Left sensor battery low | Left sensor reaches low battery threshold |
| Power | Right sensor battery low | `power_sensor_low_right.wav` | Voice | Right sensor battery low | Right sensor reaches low battery threshold |
| Power | Both sensor batteries low | `power_sensor_low_both.wav` | Voice | Sensor batteries low | Both sensors reach low battery threshold |
| Power | Left sensor battery critical | `power_sensor_critical_left.wav` | Voice | Left sensor battery critically low | Left sensor reaches critical battery threshold |
| Power | Right sensor battery critical | `power_sensor_critical_right.wav` | Voice | Right sensor battery critically low | Right sensor reaches critical battery threshold |
| Power | Both sensor batteries critical | `power_sensor_critical_both.wav` | Voice | Sensor batteries critically low | Both sensors reach critical battery threshold |
| Fault | Left sensor fault | `fault_sensor_left.wav` | Voice | Left sensor fault | Left distance readings remain invalid |
| Fault | Right sensor fault | `fault_sensor_right.wav` | Voice | Right sensor fault | Right distance readings remain invalid |
| Fault | Both sensors faulty | `fault_sensor_both.wav` | Voice | Sensor fault | Both distance readings remain invalid |
| Fault | Communication fault | `fault_comm.wav` | Voice | Communication fault | Communication or protocol error |
| Fault | System fault | `fault_system.wav` | Voice | System fault | Critical system error |
| Distance | Slow beep | `beep_slow.wav` | Distance beep | Slow repeating beep | Far distance |

| Distance | Fast beep | `beep_fast.wav` | Distance beep | Fast repeating beep | Close distance |
| Distance | Continuous beep | `beep_continuous.wav` | Distance beep | Continuous beep | Dangerously close distance |
